# CUMT 校园网登录器

一个用于中国矿业大学校园网的 Windows 桌面工具。软件可以检测校园网连接和登录状态，并自动完成登录。

## 主要功能

- 保存账号、密码和运营商选择。
- 检测当前是否连接校园网。
- 显示校园网登录状态。
- 支持手动登录、注销和刷新状态。
- 支持检测到校园网未登录时自动登录。
- 支持后台定时检测连接状态。
- 支持系统托盘、系统通知和连通性测试。
- 额外适配门户返回“当前时段不允许上网”等异常情况，识别后会通知用户。

## 主页

主页用于完成日常登录操作。顶部显示当前连接的校园网名称和登录状态；中间是账号、密码、运营商配置；下方提供连通性测试、网络详情和运行日志入口。

## 设置

设置页用于控制关闭行为、通知、开机自启动、后台检测和自动登录。

<p align="center">
  <img src="docs/images/settings.png" alt="设置" width="420">
</p>

主要选项：

- 关闭后：选择最小化到托盘或直接退出。
- 启用系统通知：登录、断联、异常情况会通过 Windows 通知提醒。
- 启用开机自启动：开机后自动启动软件。
- 后台定时检测连接状态：按设定间隔持续检测登录状态。
- 检测到校园网未登录时自动登录：检测到已连接校园网但未登录时自动尝试登录。

## 托盘

软件可以常驻系统托盘。托盘顶部会显示当前登录状态，菜单中可以快速执行常用操作。

- 刷新状态
- 一键登录
- 注销
- 打开登录页
- 退出


## 自动检测与自动登录

即使关闭后台定时检测，启动时仍会自动检测登录状态。

如果开启自动登录，软件在检测到已连接校园网但未登录时会尝试登录。

以下情况会暂停本次运行内的自动登录：

- 用户主动注销。
- 当前时段不允许上网。
- 登录设备超限。
- 账号不存在。
- 账号或密码错误。

暂停后，软件仍会检测和登录。手动登录成功后会恢复自动登录。

## 数据位置

配置和日志保存在：

```text
%APPDATA%\CUMT Campus Login\
```

## 运行说明

下载zip后解压到想要的文件夹，运行：

```text
CUMT-Campus-Login.exe
```

不要单独移动 exe，保留完整文件夹。
